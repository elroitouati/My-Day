# My Day

מנהל משימות יומי לאנדרואיד, עם **ווידג'ט אינטראקטיבי** למסך הבית שבו מסמנים V על משימות בלי לפתוח את האפליקציה.
כולל אירועים מ-Google Calendar וסנכרון דו-כיווני עם אפליקציית פנמ"צ.

**להתקנה — ראה [SETUP.md](SETUP.md).**

## מה יש בפנים

- **משימות:** כותרת, קטגוריה בצבע, הערות, שעה (או "כל היום"), חד-פעמית או קבועה
  (כל יום / ימים בשבוע / כל X ימים / פעם בחודש). השלמה נשמרת לכל מופע ותאריך בנפרד,
  ומשימה שלא סומנה נשארת ביום שלה כ"פספוס".
- **מסכים:** היום · שבוע (ציר זמן) · חודש (לוח עם נקודות) · הגדרות, וכפתור + צף.
- **ווידג'ט:** משימות היום מכל המקורות, פס התקדמות, סימון V ישירות מהמסך.
- **התראות:** לפני משימה עם שעה (עם כפתור "בוצע"), ותזכורת ערב על משימות פתוחות.
- **Google Calendar:** קריאה מהיומנים שבטלפון; אפשר לסמן V על אירוע (נשמר מקומית).
- **פנמ"צ:** האימונים של היום מופיעים כמשימות, וסימון בכל צד מתעדכן בשני (Supabase + Realtime).

## טכנולוגיה

Expo SDK 51 · React Native 0.74 · JavaScript · SQLite (`expo-sqlite`) · `react-native-android-widget` ·
React Navigation · Reanimated · `expo-notifications` · `expo-calendar` · `expo-background-fetch` · Supabase.
ממשק בעברית ו-RTL מלא, גופן Heebo. בנייה דרך EAS (`eas build -p android --profile preview`).

## מבנה

```
index.js                  נקודת כניסה: אפליקציה, מטפל ווידג'ט, משימת רקע, תגובות להתראות
App.js                    ניווט (טאבים + מסך יום), גופנים, RTL
src/logic/                לוגיקה טהורה ומכוסה בבדיקות: תאריכים, חזרה, עריכה, איחוד מקורות, מיזוג סנכרון
src/db/                   SQLite: מיגרציות ושאילתות
src/services/             התראות, יומן, Supabase/פנמ"צ, רענון ורקע
src/widget/               הווידג'ט ומטפל הלחיצות שלו
src/screens/, src/sheets/, src/components/   הממשק
supabase/schema.sql       טבלה, RLS, "האחרון קובע" ו-Realtime
plugins/withForceRTL.js   RTL כבר מההפעלה הראשונה
panmatz-patch/            השינויים לפנמ"צ כ-patch (גיבוי לענף feature/my-day-sync)
```
